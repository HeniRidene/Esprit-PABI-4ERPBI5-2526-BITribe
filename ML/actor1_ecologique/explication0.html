Actor 1: Ecological Impact Pipeline

A detailed breakdown of the `actor1_ecologique.ipynb` notebook logic, models, and outputs.

1. Data Loading

Code Logic: The notebook begins by importing essential libraries (Pandas, Numpy, plotting libraries, XGBoost, etc.) and initializing the filesystem path. It loads the core dataset via a merge between the fact_impact_territorial.csv table and dimension tables (dim_temps.csv, dim_zone.csv). It also handles data sanitization by removing phantom/invalid zones and inspecting the memory footprint.

Image Output: No visualization generated in this cell. It strictly prepares the dataset for downstream tasks.

2. Feature Engineering

Code Logic: Critical preprocessing steps are executed here. The notebook eliminates null values across target features (co2_kg, aqi_index, energie_kwh). Next, categorical variables like operational zones and transportation lines are ordinalized/encoded. To capture temporal trends, moving averages and lag features (e.g., co2_lag1) are synthetically generated.

Output Image: Feature Correlation Matrix Heatmap

A Seaborn heatmap showing linear correlations between variables. It highlights collinearity (e.g., strong links between CO2 and energy consumption) allowing us to drop redundant predictors.

3. Regression (CO2 & Energy)

Code Logic: The goal here is strict estimation of co2_kg and energie_kwh. The pipeline uses two main algorithms:

  • Lasso Regression: Used as a sparse, L1-regularized baseline. Standard scaling is applied beforehand.
  • XGBoost Regression: A gradient-boosting approach heavily tuned using GridSearchCV on historical lag features.
Energy R² (XGBoost)
0.71
CO2 R² (XGBoost)
0.20

Note: The CO2 R² is low because monthly aggregation masks high-frequency hourly emission spikes.

Output Image: Residual Plots (XGBoost vs Lasso)

Two side-by-side scatter plots showing Predict vs. Actuals/Residuals. These visualize the homoscedasticity of the errors. XGBoost visually compresses residuals much tighter to the zero-line than Lasso for the Energy predictions.

4. Clustering Analysis

Code Logic: Exploring spatial profiles without labeled targets natively using K-Means and DBSCAN. The algorithms parse multidimensional pollution vectors per zone (pm25, no2, co2_kg). The workflow computes Elbow inertia and Silhouette scores across K=[2..8] to pinpoint the mathematically optimal cluster configuration.

Best K (K-Means)
k = 2
Silhouette Score
0.32
Output Image 1: Elbow and Silhouette Curve

Line charts indicating the trade-off between inertia and cluster distinctness. Both metrics agree on k=2 as optimal.

Output Image 2: 2D PCA Cluster Map

A scatter plot mapping high-dimensional zone features to 2 principal components. Zones are colored by their K-Means assignments, clearly displaying two distinct "Pollution Profiles" (e.g. Urban Core vs Suburban outskirts).

5. Time Series Forecasting

Code Logic: Forecasting AQI (Air Quality Index) specifically for Zone 1. The notebook isolates the zone, filters the indices chronologically, and subjects the series to the Augmented Dickey-Fuller (ADF) test to mathematically confirm stationarity. It then trains two temporal statistical models: SARIMA (classical) vs Prophet (Facebook's additive model).

Output Image 1: Seasonal Decomposition

A stacked 4-panel chart showing Observed, Trend, Seasonal, and Residuals. Shows clear cyclic behaviors in AQI spikes corresponding to months of the year.

Output Image 2: Forecast Comparison

Displays Historical AQI along with future predictions mapped via SARIMA and Prophet. Prophet achieves a superior MAE of 1.92 on a 3-step holdout, outperforming classical SARIMA.

6. Business Insights

Conclusion: The notebook concludes by weaving model outputs into actionable strategy. It validates that XGBoost performs excellently on Energy predictions (R²=0.71) but struggles with CO2 (R²=0.20) due to temporal granularity loss. K-Means (Silhouette 0.32) establishes two distinct intervention zones for traffic management. The predictive capability of Prophet gives policymakers a functional gauge for short-term (1-3 months) localized AQI spikes.
